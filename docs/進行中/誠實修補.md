## 分組（依根源）

### A　「回去」的指令沒看 commit 之間的關係　🔴

- A1 章之後又存了 N 次 → `reset --hard` 會讓那 N 次從分支上消失，畫面一句沒提。
- A2 章指的版本已經不在分支上（09/10 10:00 清歷史時發生）→ 照指令回去會跳到另一條歷史，
  而那條歷史裡還留著被清掉的對話紀錄。主資料夾從那時起就一直這樣顯示。

根源：AC-3 只把「還沒 commit 的檔案」當成回去會丟的東西，從沒問「章跟 HEAD 是什麼關係」。

修法：顯示前先問 git 兩件事——章還在這條分支的歷史上嗎？之後有幾個 commit？
三種答案三種畫面：不在 → 章失效、**不給任何回去指令**；在、後面有 N 個 → 先備份分支再回去；
在、就是現在 → 照舊。

### B　同一個畫面上的數字彼此對不起來　🔴

- B1 `git add` 過的改動顯示「沒有改動」，同畫面又說「2 個檔案還沒存進保險箱」
  （沒章時用 `git diff`，看不到 add 過的；「保險箱」那句用 `git status`，看得到）。
- B2 新資料夾裡 3 個檔顯示「會丟掉 1 個」（`git status` 把整個資料夾算一行）。
- B3 只刪不加顯示「+0 −0」（假設一定有 insertion 字樣）。

根源：「改動」被問了三次、三種問法，各有盲點。L2 同一形狀第三次 → 老毛病 P1／P2。

修法：一個基準（有章比章，沒章比 HEAD）、`git status -uall`、加減行分開讀。
測試釘「同一畫面的數字必須自洽」。

### C　「這個專案是誰」有三套算法　🟠（第 3 批）

- C1 資料夾名有空白／中文 → 永遠「還沒有紀錄」（hook.sh 把不安全字元換成 `_` 存檔，讀取端拿原名找）。
- C2 子資料夾執行 → 專案名變上一層（git 從子資料夾回相對路徑 `../.git`，被接在錯的資料夾後面）。
- C3 還原點檔名又是第三種規則 → 中文名專案在網頁上會變兩張卡。

根源：「專案名 → 檔名」三處各寫一次 → 老毛病 P2。

修法：JS 一個 `safeName()` 逐位元組跟 hook.sh 的規則一樣；讀紀錄、寫章都用它。
測試**真的跑 hook.sh**，餵一個有空白和中文的名字，斷言讀取端找得到。

### D　「感測器活著嗎」問錯地方　🟠（第 2 批）

- D1 worktree 沒有自己的設定檔 → 「沒掛上」，但紀錄裡明明有這個對話的紀錄（用的是主資料夾的設定）。
- D2 故障記號是全機一份，一有故障就把五關整區蓋掉，幾千筆紀錄也一樣。
- D3 網頁沒畫「掛著但壞了」（L13 只做了一半）。

根源：「活著」要看紀錄才知道，設定檔只能回答「掛在哪」。

修法：拆成「掛在哪」＋「最後一筆來自這裡的紀錄是 N 分鐘前」；故障降成一行警告；網頁補上。

### E　零星、彼此獨立

- E1 透過捷徑（symlink）執行什麼都不印（L1 同族 → P3）（第 3 批）
- E2 檢查跑不起來 vs 跑了沒過分不開，錯誤全藏（第 2 批）
- E3 worktree 第一則訊息記到系統附加的說明（第 2 批，hook.sh 只動這一處）
- E4 主資料夾 `npm test` 掃到 `.claude/worktrees/` 裡的副本（第 3 批）
- E5 TutorPod 的 CLAUDE.md 寫著搬家前的路徑（另開對話改，不在這個 repo）
- E6 `.gitignore` 漏了 `.claude/settings.local.json` → 主資料夾蓋不了章，而它建議的 `git add -A`
  會把這個檔案存進去（第 1 批，L12 同一個動作的兩半）

### 2026-09-11　第 1 批：A、B、E6（＋決定 2 的機制）

**A　回去的指令**
- `status.mjs` 新增 `checkpointRelation()`：先問「章的版本還在嗎」，再問「還在這條分支的歷史上嗎」，
  再問「之後有幾個 commit」。四種答案 `ok`／`off-branch`／`gone`／`unknown` 刻意分開，只有 `ok` 才給指令。
- 還原點那一段的文案抽成純函式 `describeCheckpoint()`＋`restoreAdvice()`，
  測試釘住「章不能用時輸出裡不准有 `reset --hard`」、「有存檔要丟時 `git branch 備份-…` 在 reset 前面」。
- 章不能用時，改動體檢的基準退回 HEAD，畫面講明「章失效了，所以這裡比的是上一次存檔」。
- 網頁（`lib/collect.mjs` → `ui/app.js`）用同一個判斷：失效的章畫成「失效」、**沒有複製按鈕**；
  章之後有存檔時，複製出來的指令是 `cd … && git branch 備份-… && git reset --hard …`，備份沒成功走不到 reset。
- 實測主資料夾：它的章指的版本在這一天之內已經被 git 清掉了（物件不存在），畫面現在說「它指的版本已經不存在了」，不給指令。
