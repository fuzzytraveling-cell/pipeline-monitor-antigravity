# 功能：分級 —— 這一次改動要多小心

> 2026-09-13 開工。Oscar 的決定（09-11／09-13）：不擋；危險清單人手寫在設定檔、TutorPod 的 `tier.mjs` 改讀同一份；
> 只准往上調（對話、指令、儀表板按鈕三條路，理由必填）；程式區自己在設定檔定義，沒定義就不分級；
> 對話開始時 Claude 主動提醒一次；**不做**「一鍵自動建立」按鈕。

## 這是為了解決什麼

五關是「該做哪些事」，但沒有東西回答「**這次**該做到哪幾關」。改 README 跟改資料層被要求做一樣多的事，
結果是人自己決定要不要跳過——而 TutorPod 2026-09-08 就是這樣漏掉一次 `/chaos-check`（見它的 `tier-prints-triggers.md`）。

分級把「這次要多小心」變成查表：這次改的檔案落在哪裡 → 哪幾關必須有紀錄。

## 白話

- 分級**不是專案的屬性**，是這一次改動的屬性。同一個專案早上改 README 是 T0，下午改匯出程式是 T2。
- 依據只有一個問題：檔案落在哪裡。兩張清單都是**人寫的**：程式區（程式住的資料夾）、危險清單（改錯了不會馬上看見、
  幾天後才發現使用者的東西壞了的檔案）。
- 「危險」的判準不是重不重要，是**改錯了會不會靜默丟資料**。畫面改錯看得見；資料層改錯，幾天後在別台裝置才發現。

## 驗收條件

**AC-1　沒有清單就不分級，而且不准折成最低那級**
> 設定檔沒有 `tiers` → 畫面說「還沒設定分級」＋怎麼設定；讀不懂 → 說「讀不懂，這次不分級」；
> 明講不分級（`tiers.off`）→ 說「已設定為不分級」。三種各自一張臉，沒有一種會顯示 T0（R1）。

**AC-2　機器算的只看檔案落在哪裡，而且是下限**
> 基準跟改動體檢同一份（有章比章，沒章比上一次存檔）。碰到危險清單 → 第三級；碰到程式區 → 第二級；都沒 → 第一級。
> 畫面寫「至少 T1」，並說明是哪幾個檔案讓它變成這一級。

**AC-3　「需要」那幾行只講有沒有紀錄，不講通過（R2）**
> 每一級需要的關，各自顯示：✅ 有紀錄且你說處理完了／⏸ 有紀錄還沒結案／⚠️ 沒有紀錄／❔ 問不到或不適用。
> 「補測試」看的是 git 事實：這次有沒有新增或修改任何測試檔。**不擋蓋章**。

**AC-4　危險清單空的要明講**
> 「危險清單是空的，所以永遠不會出現 T2」。不讓空的看起來像都安全。

**AC-5　只准往上調，理由必填，跟著這次改動走**
> `--tier T2 "理由"`、對話裡說一句、儀表板的「調高」——三條路寫同一種紀錄（`tier_set`，source:human）。
> 只列比機器算的高的等級；收回（`tier_retracted`）只回到機器算的；往下沒有指令。
> 基準換了（有章時蓋章之後、沒章時存檔之後）就歸零。畫面寫「機器算 T1，你說 T2（理由）」。

**AC-6　對話開始時提醒一次，不多**
> `remind.sh` 掛 SessionStart：是 git 專案、沒退出記錄、沒有 `tiers` → 給 Claude 一行。resume／compact 不提。
> 說「這個專案不用分級」寫進設定檔後不再提。這是**第二支 hook，契約跟 `hook.sh` 相反**，刻意分開兩支檔案。

**AC-7　工具不猜危險清單，但可以提醒**
> `--tier-init` 只提議程式區（package.json 指向 → git 追蹤的程式檔 → 硬碟上的程式檔），危險清單留空。
> 「這次動到、在程式區、名字像會存東西、不在危險清單」的檔案，畫面提醒一句——只提醒，不決定。
> plugin 帶一個 skill：任何專案裡說「幫我設定分級」，Claude 拿到同一份做法（三個問題、先提案再寫）。

**AC-8　設定要進版控**
> 分級是專案政策。`--tier-init` 發現 `.claude/pipeline-stages.json` 被 gitignore 時明講，並給要加的那一行。
> 讀取端在 worktree 找不到時退回主資料夾找（`.claude/*` 常被 ignore，不跟著 checkout）。

**AC-9　程式碼裡沒有任何專案專屬的字串**
> T0／T1／T2 與「需要哪幾關」住在 `stages.json` 的 `tierLevels`（專案可用 `tiers.levels` 覆寫）。
> `status.mjs`／`lib/tier.mjs` 裡不准出現這些字串。

## 刻意不做

- **不做儀表板「自動建立分級」按鈕。** 按鈕只能做程式區那半，危險清單那半機器做不到；做了會得到一份看起來設定好了、
  其實最重要的那半沒做的東西。
- 不做往下調的指令。要往下改設定檔。
- 不做 e2e 的自動驗收。那是 E 證據帳的事，另開規格。

`tier.mjs` 改讀同一份、`.gitignore` 加 `!.claude/pipeline-stages.json`——三件事在 TutorPod 那個 repo 做，另開對話。
