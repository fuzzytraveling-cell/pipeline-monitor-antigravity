## 這是為了解決什麼

Antigravity 儀表板（4320）目前長得跟 Claude 儀表板（4319）幾乎一樣，並排開著時容易搞混；換成「夜間工班」暗色霓虹主題並加上 `Antigravity` 識別後，一眼就能分出現在看的是 Antigravity，同時保留熟悉的工班角色與防說謊規矩。

## 混沌推導

▸ **時間**：每 5 秒整頁重畫 → 所有霓虹光暈與光流動畫照舊吃 `--t` 負延遲，不每 5 秒跳回起點；斷線超過時限 → `body.dim` 與頂列反白膠囊在暗底上照樣醒目。
▸ **輸入畸形**：伺服器回傳畫面不認得的狀態 → 問號眼照舊發黃光且在暗底上清晰；舊的服務還沒 `--serve-restart` → 故障橫條與舊服務提醒在暗底上清晰可讀。
▸ **權限／離線**：完全不連外部網路（不載入外部字型、圖檔、CDN），斷網下暗色霓虹與系統字型完全正常。
▸ **系統環境**：macOS 原生 `<select>`／捲軸在未宣告 `color-scheme: dark` 時會畫白底 → AC-7 明確處理；使用者開「減少動態效果」→ AC-6 全部動畫靜止。

## 明確不做

- **不做日夜模式切換開關**：Antigravity 版固定為「夜間工班」，藉此與原版 Claude 看板（4319）天然區隔，也不額外維護兩套色票。
- **不改任何後端資料判斷與終端機文案**：什麼時候算「現在這一關」、什麼時候警示、什麼時候亮燈、終端機與網頁共用句子一律不動。
- **不改成純線框霓虹角色、不換六個角色的形狀或工地帽樣式**：維持原本六個形狀、帽子與表情語意，不畫嘴、不畫手腳、不做點頭。
- **不加任何外部字型、圖片檔、npm 相依或新路由**：常駐服務白名單不增新檔。
- **不做手機版**。
