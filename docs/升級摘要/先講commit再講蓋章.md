另動 `scripts/` 的 ui、collect、status 測試與 `docs/FAILURE-PATTERNS.md`）。T1 要 D。危險清單上的檔一支都不碰——寫程式時發現非碰不可，就是 T2，先回來講。

> 2026-10-29 用 `/pipeline-monitor:spec` 寫的。起因：Oscar 在 AI Automation Suite 的對話頁（第 3 階段第 2 輪）看兩張截圖搞混了。
> 第一張「23 個檔案、其中 3 個還沒存進保險箱」，他讀成「這是還沒 commit 的清單」；commit 完之後第二張還是 23 個，

## 這是為了解決什麼

第三張卡把「改過幾個」放大字、「還沒 commit 幾個」放小字，標題又寫死「未檢查清單」，所以每次都要猜它在講 commit 還是在講蓋章。
第一張截圖那 3 個沒 commit 的，只有 1 個露在外面，另外 2 個藏在「還有 18 個檔案」裡。
還原點那句警告不管有沒有東西沒存都掛著，讀起來就是「你現在有東西沒存」。

## 白話

出貨分兩關：先打包（commit），再驗貨蓋章（蓋章）。走過去只想問兩件事：還有哪幾箱沒打包？打包完了，還有哪幾箱沒驗？
現在這張單子把兩關混在一張表上，表頭還寫著「未驗貨清單」，而且門口那塊「小心有箱子沒打包」的牌子從來不收。

## 驗收條件

**AC-1　還有檔案沒 commit 的時候，卡片先講這件事：大字是還沒 commit 幾個，清單只列這幾個** ✅ 對過 2026-10-29
> **白話**：看這張卡的第一個問題是「存了沒」，卡片第一眼就回答它。
> **會發生的情況**：第一張截圖那一刻（蓋章之後改過 23 個、其中 3 個沒 commit）→ 大字「3 個檔案還沒 commit」，清單只列那 3 個。
> 檔案多的時候照舊只露前 5 個，其餘收進「還有 N 個檔案」（工地工班風畫面 AC-13）。新建的檔照舊標「新檔案」。「其中 3 個還沒存進保險箱」那一行不再出現。
> **技術**：清單就是 `dirtyPaths()`（`git status --porcelain -uall`）那一份，大字是它的長度。不能用「改過的清單裡標了還沒存的那幾個」（原因見 AC-2）。伺服器分好組帶過去，網頁照畫。

**AC-2　同一刻，「還沒 commit 幾個」整頁只有一個數字：三階梯第一格、還原點那句、這張卡的大字與清單，四處一樣** ✅ 對過 2026-10-29
> **白話**：同一件事四個地方講，數字一不一樣，你就不知道該信哪一個。這次就是這樣搞混的。
> **會發生的情況**：蓋章之後改了一個檔、commit，又把它改回蓋章時的樣子，還沒 commit。今天三階梯說「還有 1 個檔案沒存」，第三張卡卻說「沒有改動」
> （它跟蓋章時一模一樣，不在「改過的」清單裡）；照新的排法，就會變成三階梯說 1 個、這張卡說「都 commit 了」。改完四處都說 1 個，清單也列出它。
> **技術**：一次刷新只問一次 git status，四處都從那一份來。FAILURE-PATTERNS 的 P2 補一條：卡片數的是「改過的」裡面還沒存的，三階梯數的是全部。
> 測試照上面那個情況造一個資料夾，四處各讀一次。

**AC-3　有東西沒 commit 的時候，已經 commit、還沒蓋章的那些不會消失：留一行「另外 N 個已經 commit、還沒蓋章」，點開才列檔名** ✅ 對過 2026-10-29
> **白話**：不留這一行的話，commit 完最後 3 個，大字會從 3 一下跳成 23，看起來像突然冒出 20 個問題。
> **會發生的情況**：第一張截圖那一刻 →「另外 20 個已經 commit、還沒蓋章」，預設收著，點開列那 20 個，重新整理也記得開著還是收著。
> N 是 0 就整行不出現。一般情況下 3 ＋ 20 ＝ 蓋章之後改過的 23 個。
> **技術**：N 是「從起點改過」的那張清單（現在的 `listChangedFiles`，跟分級同一張）扣掉 AC-1 那一份。伺服器算，網頁照印。

**AC-4　都 commit 了，卡片改講「還沒蓋章」：大字是蓋章之後改過幾個，底下一行講怎麼蓋** ✅ 對過 2026-10-29
> **白話**：打包完了，下一個問題是「還有哪些沒驗」。
> **會發生的情況**：第二張截圖那一刻 → 大字「23 個檔案還沒蓋章」，底下一行「都 commit 了，這些是蓋章之後改的。要蓋章：在那個資料夾跑 `pipeline-status --checkpoint`」，
> 清單列這 23 個（照舊只露前 5 個）。重新蓋章之後，照舊顯示「沒有改動」「現在的檔案跟蓋章時一模一樣」。
> 不加任何綠色或打勾（老毛病 P10）：蓋過章只代表檢查全綠。
> **技術**：只有 AC-1 那一份**問得到、而且是空的**，才走這一段（AC-6）。「在那個資料夾跑」跟還原點卡「還沒有還原點」那一種用同一個說法。

**AC-5　沒有能用的章，或連這一輪從哪開始都找不到：照實講看得到的範圍，不講成「沒有還沒蓋章的」** ✅ 對過 2026-10-29
> **白話**：沒有章可以比的時候，「還有哪些沒蓋章」答不完整。答不完整就說答到哪裡，不要裝作答完了。
> **會發生的情況**（「還沒 commit」那一段三種都跟 AC-1 一樣，差在後半）：
> - 沒蓋過章或章失效、找得到這一輪的起點 →「另外 N 個已經 commit、還沒蓋章（只算這一輪改的）」；都 commit 之後，大字「N 個檔案還沒蓋章」，
>   底下一行「都 commit 了，還沒有能用的章；這裡只算這一輪改的」。
> - 找不到這一輪的起點 → 那一行改成「commit 過、還沒蓋章的有哪些，這裡看不到（找不到這一輪開始時的版本）」；都 commit 之後，大字「都 commit 了」，
>   底下同一句「看不到」。不畫「沒有改動」。
> - 這個專案一個 commit 都沒有 → 只有「還沒 commit」那一段，再加一句「還沒有任何 commit，所以也還沒有東西可以蓋章」。
> **技術**：`changeScope()` 已經分得出這幾種（`blind`、`emptyBlind`、`why`），原因那半句照它給的。老毛病 P5：一個 0 有兩種意思。

**AC-6　問不到哪些還沒 commit 的時候，就講問不到，不跳去講「都 commit 了」** ✅ 對過 2026-10-29
> **白話**：沒問到不等於沒有（紅線 R1）。
> **會發生的情況**：git 一時問不到（資料夾正被別的程式鎖著、git 壞了）→ 大字「問不到」，底下「問不到你有沒有還沒 commit 的檔案。」，
> 不出現「都 commit 了」，也不出現「N 個還沒蓋章」。還原點那句同樣講問不到（AC-9），三階梯照舊「問不到有沒有沒存的檔案」。
> **技術**：AC-1 那一份是 null 就停在這裡。底下那句跟還原點「問不到」那一句是同一份（AC-9）。測試讓 git 問不到，確認卡片上沒有「都 commit 了」。

**AC-7　標題固定講主題、不講狀態；灰色小字固定問「commit 了沒、蓋章了沒」** ✅ 對過 2026-10-29
> **白話**：標題寫死一個狀態，狀態一變它就說錯。9/15 把「commit 後還沒被檢查」讀成「還沒 commit」，這次又一次。
> 寫主題就不會錯，另外三張卡也是這樣寫的（還原點、三階梯、分級）。
> **會發生的情況**：每一種狀況，標題都是「存檔與蓋章」（Oscar 10/29 點頭），灰色小字都是「commit 了沒、蓋章了沒」。
> 「未檢查清單」「蓋章之後改過、還沒重新檢查的檔案」「這一輪改過的檔案（含已存檔的）」這幾行不再出現在這張卡上。
> **技術**：狀態只寫在大字和它底下那一行。

**AC-8　卡片最下面收一段「commit 跟蓋章差在哪？」，預設收著；比例尺、從哪裡算起也一起收進去** ✅ 對過 2026-10-29
> **白話**：說明要找得到，但不要擋在你要看的東西前面（工地工班風畫面 AC-10 的三層）。
> **會發生的情況**：點開看到三句：
> - commit（存檔）：把現在的檔案存一份，之後回得去這一份。只代表存了，不代表程式能動。
> - 蓋章（`pipeline-status --checkpoint`）：在已經 commit 的那一份上，跑這個專案的檢查（還原點卡上列的那幾項），全綠才蓋。
>   還原點卡上的時間，就是最近一次蓋章。⚠️ 檢查全綠不等於功能正確——測試沒測到的地方它不知道。
> - 一定先 commit 再蓋章：還有沒 commit 的檔案，蓋章會直接被拒絕。
>
> 下面接「蓋章之後的改動：23 個檔案」，再接比例尺那一句（例：這個專案一次存檔通常 3 個檔案、最多到過 41 個；這裡是 4 次存檔加起來的）；
> 沒有能用的章、照這一輪算的時候，再接從哪裡算起那一句。重新整理也記得開著還是收著。
> **技術**：「全綠不等於功能正確」、比例尺、從哪裡算起、「蓋章之後的改動」這幾句 lib 都已經有，終端機也在講（`GREEN_IS_NOT_CORRECT`、`scaleLine`、`changeScope` 的 note 與 title），
> 照印、不改字。只有前三句說明是新寫的。「會被拒絕」那句照 `lib/cliStamp.mjs` 現在的做法寫，那邊的行為變了，這句要跟著改。

**AC-9　還原點那句照實際講：有東西沒 commit 才說會丟掉幾個；問不到就說問不到；一個都沒有，只講「現在沒有還沒 commit 的檔案」** ✅ 對過 2026-10-29
> **白話**：一句永遠掛著的警告，讀起來就是「你現在有東西沒存」。這次就是被它誤導的。
> **會發生的情況**：3 個沒 commit →「⚠️ 回去會丟掉你還沒 commit 的 3 個檔案」（這個 3 跟 AC-2 是同一個數）；問不到 →「⚠️ 問不到你有沒有還沒 commit 的檔案」；
> 0 個 →「現在沒有還沒 commit 的檔案」，不帶 ⚠️（這一行留著不拿掉，Oscar 10/29 點頭）。
> 這一行照舊放在外面、位置不變（工地工班風畫面 AC-10「會害你丟東西的留在外面」照舊，只是改成講實話）。
> 蓋章之後存過的那幾次，照舊收在「為什麼？」裡（指令會先把它們留在一條備份分支上）。
> **技術**：「會丟掉 N 個」「問不到」這兩句終端機也講（`restoreAdvice`），所以收進 `lib/scope.mjs` 一份：終端機改從那裡拿（含「也會丟掉」的「也」），
> 伺服器帶給網頁（老毛病 P2）。整頁統一講「還沒 commit」（Oscar 10/29 決定），所以終端機這兩句的「還沒存」也跟著換成「還沒 commit」（AC-11）。

**AC-10　更新之後、服務還沒重啟那段時間，這兩張卡不壞、不自己拼字** ✅ 對過 2026-10-29
> **白話**：網頁換新了、背後算資料的還是舊的，這時不准印出空白或程式內部的值。
> **會發生的情況**：合併之後還沒 `--serve-restart` → 缺新資料的地方照這個專案的老規矩寫「（服務還在跑舊的程式）」，頁面最上面講怎麼修；
> 不出現 undefined、null、空白的大字，也不拿舊資料硬湊出新的那幾種狀況。
> **技術**：伺服器只加欄位、不拿掉舊的。`scripts/ui.test.mjs` 用舊的卡片資料跑一次新的 `statChanges`／`statRestore`。

**AC-11　終端機這次只換一個詞：同一刻、同一個資料夾，改之前跟改之後各跑一次 `pipeline-status`，只有「怎麼回去」那兩句的「還沒存」變成「還沒 commit」** ✅ 對過 2026-10-29（改名 add 過、還沒 commit 的那一筆，終端機數的「還沒存」從 1 個變 2 個——新舊兩個路徑都算，Oscar 10/29 接受）
> **白話**：這次只改網頁。終端機要不要跟著改，等你用過新的網頁再說；唯一的例外是跟網頁共用的那兩句（AC-9）。
> **會發生的情況**：有章且有東西沒存、有章且都存了、沒章、章失效，四種資料夾各比一次。除了那兩句的那個詞，其他一字不差。
> **技術**：還原點那句改從 lib 拿（AC-9），是唯一碰到終端機的地方。兩邊要同一刻跑（LESSONS L38：中間有別的對話在改檔，會比出假的差異）。

## 混沌推導

▸ 時間：畫面每 5 秒拿一次資料，還原點那一行講的是那一刻。複製回去的指令之後才改的檔，貼上指令照樣會丟掉。今天就是這樣，這次不改（見明確不做）。
所以那一行只講「現在」，不講「回去不會丟東西」這種保證。
▸ 併發：別的對話正在改檔時刷新，數字會跳。但同一次刷新四處讀的是同一份（AC-2），彼此不會矛盾。
▸ 輸入畸形：檔名有空白、中文、搬過家（`R 舊 -> 新`）的，`dirtyPaths()` 已經處理。刪掉的檔也算還沒 commit，照舊列出來、不另外標。
▸ 容量：一次幾百個沒 commit 的新檔（例如產生出來的檔忘了加進 .gitignore）→ 照舊只露前 5 個；「另外 N 個」那一行預設收著。

## 明確不做

- 終端機的「改動」那一段不改（照舊列蓋章之後改過的，另外講還沒存的幾個）。收工 hook 講的話也不改。
- 三階梯第一格（「還有 N 個檔案沒存」）、案件首頁中間那幾行的字不改：「統一成還沒 commit」只管這份規格動到的句子。
- 分級、五關、收工 hook 看的範圍不改：照舊看「蓋章之後／這一輪改過的全部」，不會變成只看還沒 commit 的。
- 「複製回去的指令」不改（含 cd、備份分支）。複製之後才改的檔會被丟掉，這件事另外想。
- 卡片的顏色、位置、便條紙樣子不改；「只露前 5 個」不改；刪掉的檔不另外標。
- 不碰危險清單上的檔。
